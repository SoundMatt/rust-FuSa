# ISO 21434 Support

rust-FuSa supports ISO 21434 (Road vehicles — Cybersecurity engineering) gap analysis and threat modelling.

## Usage

```
rsfusa iso21434 [--format text|json] [--dir <path>]
rsfusa tara [--dir <path>]
rsfusa cyber [--dir <path>] [--format text|json]
```

## TARA (Threat Analysis and Risk Assessment)

`rsfusa tara` generates a TARA document per ISO 21434 Chapter 9:

1. Runs all CYBER001–CYBER020 rules against the project
2. Maps each finding to a STRIDE threat category (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege)
3. Maps each finding to its CWE identifier
4. Assigns a risk rating (CRITICAL / HIGH / MEDIUM / LOW)
5. Writes `tara.json` and `tara.md`

## Gap analysis coverage

| ISO 21434 Requirement | Evidence File |
|----------------------|--------------|
| Cybersecurity planning | `.fusa.json` |
| Asset identification | `tara.json` |
| Threat scenario identification | `tara.json` |
| Attack path analysis | `tara.json` |
| Risk assessment | `tara.json` |
| Vulnerability scan | `vuln.json` |
| Cybersecurity testing | `.fusa-evidence.json` |
