# ISO 26262 Support

rust-FuSa supports ISO 26262 Part 6 (Product development at the software level) gap analysis.

## Usage

```
rsfusa iso26262 [--format text|json] [--dir <path>]
```

## Coverage

The gap report checks for evidence files against ISO 26262 Part 6 requirements:

| Requirement | Evidence File | Clause |
|-------------|--------------|--------|
| Software safety plan | `.fusa.json` | 6.5.1 |
| Software safety requirements | `.fusa-reqs.json` | 6.5.2 |
| Software design | `boundary.mermaid` | 6.5.3 |
| Software implementation guidelines | `check-report.json` | 6.5.4 |
| Software unit verification | `.fusa-evidence.json` | 6.5.5 |
| Software integration testing | `trace.json` | 6.5.6 |
| Software qualification | `qualify-report.json` | 6.5.7 |
| FMEA | `fmea.json` | 6.4.3 |
| SBOM | `sbom.json` | 6.4.8 |
| SCI | `sci.json` | 6.4.9 |

## ASIL levels

Configure target ASIL in `.fusa.json`:

```json
{
  "configVersion": "1.0",
  "project": { "name": "myproject", "version": "1.0.0" },
  "standard": "iso26262",
  "asil": "ASIL-B"
}
```

Valid values: `QM`, `ASIL-A`, `ASIL-B`, `ASIL-C`, `ASIL-D`.

## ASIL derivation

Use `rsfusa hara asil` to derive ASIL from Severity (S1-S4), Exposure (E1-E4), and Controllability (C1-C3) per ISO 26262 Part 3 Table 4:

```bash
rsfusa hara asil --severity S3 --exposure E4 --controllability C2
# → ASIL = ASIL-C
```
