# IEC 62443 — IACS Cybersecurity

IEC 62443 is the international standard for Industrial Automation and Control Systems (IACS) cybersecurity. rust-FuSa maps evidence artefacts to the key requirements across parts 2-1, 2-4, 3-2, 3-3, 4-1, and 4-2.

## Gap report

```bash
rsfusa iec62443 --dir .
rsfusa iec62443 --dir . --format json --output iec62443-report.json
```

## Requirement mapping

| Clause | Title | Evidence file |
|--------|-------|---------------|
| IEC62443-2-1.4.3.5 | Threat and risk analysis | `tara.json` |
| IEC62443-2-4.3.1 | Security requirements specification | `.fusa-reqs.json` |
| IEC62443-3-2.5.4 | Security risk assessment | `tara.json` |
| IEC62443-3-3.SR1.1 | Security design (component boundary) | `boundary.mermaid` |
| IEC62443-4-1.SM5 | Security testing | `.fusa-evidence.json` |
| IEC62443-4-1.SM7 | Vulnerability management | `vuln.json` |
| IEC62443-4-1.SM8 | Patch management (SBOM) | `sbom.json` |
| IEC62443-4-1.SVV4 | Static code analysis | `check-report.json` |
| IEC62443-4-2.CR1.1 | Credential management (cyber scan) | `cyber-report.json` |
| IEC62443-4-2.CR7.1 | Audit log capability | `audit-pack.zip` |

## Generating evidence

```bash
rsfusa tara --dir .                   # IEC62443-2-1.4.3.5, 3-2.5.4
rsfusa check --dir .                  # IEC62443-2-4.3.1 (via .fusa-reqs.json), 4-1.SVV4
rsfusa boundary --dir .               # IEC62443-3-3.SR1.1
rsfusa verify --dir .                 # IEC62443-4-1.SM5
rsfusa vuln --dir .                   # IEC62443-4-1.SM7
rsfusa release --dir .                # IEC62443-4-1.SM8 (sbom.json)
rsfusa cyber --dir .                  # IEC62443-4-2.CR1.1
rsfusa audit-pack --dir .             # IEC62443-4-2.CR7.1
```
