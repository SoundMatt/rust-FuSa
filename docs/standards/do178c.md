# DO-178C Support

rust-FuSa supports DO-178C (Software Considerations in Airborne Systems and Equipment Certification) evidence generation and gap analysis.

## Usage

```
rsfusa do178c [--format text|json] [--dir <path>]
rsfusa sas [--dir <path>]
rsfusa sci [--dir <path>]
```

## DAL levels

Configure target DAL in `.fusa.json`:

```json
{
  "configVersion": "1.0",
  "project": { "name": "myproject", "version": "1.0.0" },
  "standard": "do178c",
  "dal": "DAL-B"
}
```

Valid values: `DAL-A`, `DAL-B`, `DAL-C`, `DAL-D`.

## Software Accomplishment Summary (SAS)

`rsfusa sas` generates the SAS document required by DO-178C §11.20:

- Checks for all required lifecycle data items
- Includes conformance statement
- Writes `sas.md` (or `sas.json` with `--format json`)

## Software Configuration Index (SCI)

`rsfusa sci` generates the SCI document required by DO-178C §11.16:

- Lists all lifecycle data items with SHA-256 hashes
- Writes `sci.json` (or `sci.md` with `--format md`)
