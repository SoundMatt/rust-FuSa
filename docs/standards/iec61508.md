# IEC 61508 Support

rust-FuSa supports IEC 61508 Part 3 (Software requirements) gap analysis.

## Usage

```
rsfusa iec61508 [--format text|json] [--dir <path>]
```

## Coverage

| Requirement | Evidence File | Clause |
|-------------|--------------|--------|
| Software safety requirements specification | `.fusa-reqs.json` | 7.2 |
| Software architecture design | `boundary.mermaid` | 7.3 |
| Software design and development | `check-report.json` | 7.4 |
| Software module testing | `.fusa-evidence.json` | 7.5 |
| Software integration testing | `trace.json` | 7.6 |
| Software safety validation | `qualify-report.json` | 7.7 |
| FMEA/FMECA | `fmea.json` | 7.4.2.3 |
| TARA | `tara.json` | 8.2.3 |
| SBOM | `sbom.json` | 7.9 |
| Vulnerability scan | `vuln.json` | 7.9 |

## SIL levels

Configure target SIL in `.fusa.json`:

```json
{
  "configVersion": "1.0",
  "project": { "name": "myproject", "version": "1.0.0" },
  "standard": "iec61508",
  "sil": "SIL-2"
}
```

Valid values: `SIL-1`, `SIL-2`, `SIL-3`, `SIL-4`.
